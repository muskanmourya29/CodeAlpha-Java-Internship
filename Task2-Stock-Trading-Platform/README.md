# Stock Trading Platform

## Project Description

Stock Trading Platform is a Java console-based application that simulates basic stock trading using virtual money. Users can view available stocks, buy and sell stocks, manage their portfolio, and view transaction history.

## Features

- View available stocks
- Buy stocks using virtual balance
- View portfolio
- Sell owned stocks
- View transaction history
- Track remaining virtual balance
- Basic quantity validation

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming
