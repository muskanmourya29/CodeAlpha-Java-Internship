# Hotel Reservation System

## Project Description

Hotel Reservation System is a Java console-based application that allows users to view hotel rooms, make reservations, view existing reservations, and cancel bookings.

## Features

- View available rooms
- Book a room
- View reservations
- Cancel reservations
- Update room availability automatically
- Validate room availability
- Validate number of nights
- Menu-driven console interface

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming
