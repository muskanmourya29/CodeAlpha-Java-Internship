# 🎓 Student Grade Tracker

A simple **Java console-based application** to input, manage, and analyze student grades.

This project was developed as part of a Java programming task and demonstrates the use of **Java basics, OOP concepts, ArrayList, loops, conditional statements, and user input handling**.


## 📌 Features

- ➕ Add student details
- 📋 View all students
- 📊 Calculate average marks
- 🏆 Find highest marks
- 📉 Find lowest marks
- 🔍 Search student by roll number
- 🎯 Automatically calculate student grades
- 🗑️ Delete a student
- ✏️ Update student marks
- 📑 Generate a complete summary report
- ✅ Validate marks between 0 and 100
- 🔐 Prevent duplicate roll numbers
- 💻 Simple console-based interface


## 🛠️ Technologies Used

- **Java**
- **ArrayList**
- **Scanner**
- **Object-Oriented Programming (OOP)**
- **VS Code**
- **Git & GitHub**
